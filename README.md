# java-racingcar-precourse

---

## 프로그램 소개

주어진 횟수 동안 n대의 자동차가 전진 또는 멈추는 자동차 경주 게임입니다.

## 프로그램 사용 가이드

아래는 프로그램의 사용 예시입니다.(입력값은 예시입니다.) 기능에 대한 세부 사항은 구현 기능 목록에서 확인하실 수 있습니다.

0. 경주할 자동차 이름을 입력합니다.(이름은 쉼표(,) 기준으로 구분)

```
pobi,woni,jun
```

1. 시도할 횟수를 입력합니다.

```
5
```

2. 차수별 실행 결과를 출력합니다.

```
pobi : --
woni : ----
jun : ---
```

3. 최종 우승자를 출력합니다.

```
최종 우승자 : pobi
```

## 구현 기능 목록

### 입력 기능

- [x] 경주할 자동차 이름을 입력받는 기능
  - 자동차 이름은 쉼표(,)를 기준으로 구분
  - 자동차 이름은 5자 이하만 가능
- [x] 시도할 횟수를 입력받는 기능

### 핵심 기능

- [ ] 주어진 횟수 동안 경주를 진행하는 기능
  - [ ] 0~9 사이 랜덤 숫자를 뽑아서 4 이상일 경우 전진 
- [ ] 각각의 경주 결과를 집계하는 기능
- [ ] 자동차 게임을 완료 후 우승자를 계산하는 기능

### 출력 기능

- [ ] 자동차 이름 입력 안내 메시지 출력 기능
- [ ] 시도 횟수 입력 안내 메시지 출력 기능
- [ ] 경주 실행 결과 출력 기능
- [ ] 최종 우승자를 출력하는 기능
  - [ ] 우승자가 여러 명이라면 쉼표(,)로 구분

### 예외 상황

사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

- [x] 자동차 이름을 입력하지 않은 경우
- [x] 공백을 입력한 경우
- [x] 자동차 이름이 5를 초과한 경우
- [x] 시도 횟수를 입력하지 않은 경우
- [x] 시도 횟수를 숫자로 입력하지 않은 경우
- [x] 시도 횟수를 1 보다 작은 수로 입력한 경우
- [x] 중복된 이름의 차가 있는 경우
- [x] 구분자를 연속해서 입력한 경우

## 프로그램 흐름도

1. 경주에 참여할 자동차 이름을 입력받는다.
2. 경주를 시도할 횟수를 입력받는다.
3. 주어진 시도 횟수 마다 n대의 자동차는 전진 또는 멈춘다.
3. 각 경주마다 자동차 이름과 전진 결과를 출력한다.
4. 모든 경주가 끝나면 최종 우승자를 계산하여 출력한다.
